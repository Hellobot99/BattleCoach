# 배틀 코치 (Battle Coach)

**포켓몬 싱글 배틀을 하면서, 한 턴마다 코치가 알려 주는 웹 학습 게임.**

체스닷컴의 수 평가처럼, 고른 행동에 등급(묘수 · 최선 · 실수 · 블런더 …)과 한 줄 이유를 붙여 줍니다. 판이 끝나면 턴별로 복기하고, 실수한 턴은 같은 상황에서 다시 둬 볼 수 있어요.

![첫 화면](docs/screenshots/01-home.png)

> 비상업 팬 프로젝트입니다. 포켓몬 이름과 그림의 권리는 Nintendo · Creatures · GAME FREAK에 있습니다. 자세한 출처는 [아래](#출처와-권리)에 있어요.

## 무엇을 할 수 있나

- **매 턴 등급과 이유** — 8단계 등급과 「이번 턴에 쓰러뜨릴 확률이 78%였어요」 같은 한 줄 설명
- **두 가지 모드** — 랜덤 팀으로 싸우는 **자유 배틀**(3 대 3 포켓몬 챔피언스 규칙 / 6 대 6 9세대), 1단계부터 20단계까지 차례로 어려워지는 **퍼즐**
- **게임 리뷰와 다시 해 보기** — 정확도, 승률 흐름, 전환점, 약점. 실수한 턴을 같은 난수 · 같은 상대 행동으로 다시 두기
- **뉴비 도움** — 상성 표시, 누가 먼저 움직이는지, 3단계 힌트, 상성 계산기, 포켓몬 정보 창, 한국어 이름과 기술 설명
- **배틀 연출** — 쇼다운의 움직이는 스프라이트, 턴 재생 애니메이션, 배틀 음악과 울음소리

## 화면

### 배틀 설정 · 퍼즐

| 자유 배틀 설정 | 퍼즐 |
| --- | --- |
| ![배틀 설정](docs/screenshots/02-setup.png) | ![퍼즐 목록](docs/screenshots/03-puzzles.png) |

퍼즐은 1단계부터 20단계까지 있어요. 단계마다 팀이 정해져 있고(모두 3 대 3, 포켓몬 챔피언스 규칙), 이기면 정확도에 따라 별 1 ~ 3개를 받고 다음 단계가 열립니다.

난이도는 네 가지가 함께 올라가요.

| 단계 | 상대 AI | 팀 전력 | 도움 |
| --- | --- | --- | --- |
| 1 ~ 4 | 1단계 (처음엔 가끔 실수, 점점 실수가 줄어듦) | 내 팀이 강함 | 상성 · 속도 표시, 힌트 무제한 |
| 5 ~ 10 | 2단계 (불리하면 교체, 상태이상 사용) | 조금 강함 → 비슷함 | 힌트 8번 → 4번, 9단계부터 표시 끔 |
| 11 ~ 15 | 3단계 (코치와 같은 평가기로 수를 고름) | 비슷함 → 상대가 조금 강함 | 힌트 4번 → 2번 |
| 16 ~ 20 | 3단계 | 상대가 확실히 강함 | 턴 45초, 힌트 2번 → 0번 |

팀 전력은 쇼다운 랜덤 배틀의 레벨(강한 포켓몬일수록 낮게 매김)로 맞추고, 단계마다 후보 팀 조합을 20개 만들어 「보통 수준 AI」가 플레이어 쪽을 맡아 수십 ~ 120판씩 싸우게 한 뒤 목표 승률(1단계 약 92% → 20단계 약 32%)에 가장 가까운 조합을 골랐어요 (`npm run puzzles`). 시뮬레이션에서는 상대를 2단계 AI로 돌리므로 11단계 이후 실제 난이도는 표의 목표보다 조금 더 높아요.

### 배틀

![배틀 화면](docs/screenshots/05-battle.png)

- 왼쪽: 필드, 승률 막대, 코치, 배틀 기록 / 오른쪽: 기술 4개 · 교체 · 힌트 · 상성 계산기 (스크롤해도 오른쪽은 고정)
- 기술 버튼에 타입, 위력, 명중, PP와 상성(「효과가 굉장함 ×2 / 보통 / 효과 없음」)이 붙어요
- 코치 카드는 그 턴의 재생이 끝난 뒤에 나와요

| 턴 재생 | 상성 계산기 |
| --- | --- |
| ![턴 재생 애니메이션](docs/screenshots/06-turn-animation.png) | ![상성 계산기](docs/screenshots/08-type-calculator.png) |

한 턴을 한 줄씩 재생해요. 물리 기술은 돌진, 특수 기술은 타입 색 구슬, 맞으면 흔들림과 번쩍임, 효과가 굉장하면 화면 흔들림, 쓰러짐, 메가진화 · 테라스탈 연출이 있어요. 상성 계산기는 타입을 1 ~ 2개 고르면 받는 피해와 주는 피해를 보여 줍니다.

### 포켓몬 정보 창

![상대 포켓몬 정보](docs/screenshots/07-info-sheet.png)

## 실행

Node.js가 필요해요 (24에서 확인했어요).

```bash
git clone https://github.com/Hellobot99/BattleCoach.git
cd BattleCoach
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 배틀 시뮬레이터와 평가기는 같은 명령으로 뜨는 로컬 서버에서 돌아요. 그래서 지금은 실행한 컴퓨터에서만 열 수 있어요.

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 화면 + 배틀 서버 실행 |
| `npm run set-stats` | 쇼다운 랜덤 팀 생성기로 상대 세트 확률표를 다시 만들기 (`server/data/sets-*.json`) |
| `npm run ko-names` | PokeAPI에서 한국어 이름 · 설명을 다시 받기 (`server/data/ko-names.json`) |
| `npm run puzzles` | 퍼즐 20단계를 다시 만들고 시뮬레이션으로 난이도 맞추기 (`server/data/puzzles.json`, 약 3분) |

### 배틀 종료 음악 (선택)

`public/audio/victory.mp3`(이겼을 때), `defeat.mp3`(졌을 때)를 넣으면 배틀이 끝날 때 재생돼요. 없으면 직접 만든 짧은 팡파르가 나와요. 이 폴더의 음악 파일은 git에 올라가지 않아요. 원작 음원은 개인적으로만 넣어 쓰세요 ([안내](public/audio/README.md)).

## 코치는 어떻게 평가하나

머신러닝 없이 **몬테카를로 롤아웃**으로 평가해요.

1. 지금 턴에 고를 수 있는 행동마다(기술 · 테라 · 메가 · 교체, 최대 13개) 판을 복제해요.
2. 상대의 아직 드러나지 않은 기술 · 도구 · 특성 · 테라 타입과 안 나온 포켓몬은 랜덤 배틀 세트 확률대로 다시 뽑은 「가상의 판」 12개에서 계산해요. 코치가 플레이어가 모르는 정보를 쓰지 않게 하기 위해서예요.
3. 양쪽을 규칙 기반 AI로 4턴씩 굴리고, 끝나지 않으면 남은 체력으로 점수를 매겨요. 행동마다 24번 → 가망 있는 상위 6개는 72번 더.
4. 최선 행동과의 기대 승률 차이(ΔW)로 등급을 매겨요: 최선 ≤ 1%p, 우수 ≤ 3, 무난 ≤ 6, 부정확 ≤ 12, 실수 ≤ 25, 그 이상 블런더.

플레이어가 고민하는 동안 미리 계산해 두고, 워커 스레드 8개로 나눠 돌려서 한 번 평가에 평균 0.8초 정도 걸려요 (Apple M4 기준). 상대 AI는 1 · 2단계가 규칙 기반이고, 3단계(퍼즐 후반)는 같은 평가기로 자기 수를 골라요.

등급 기준값은 아직 플레이 테스트로 맞추지 않은 임시 값이에요.

## 구조

```
server/            배틀 서버 (Vite 개발 서버 안에서 돈다)
  game.mjs         한 판 진행, 한국어 배틀 기록, 드러난 정보 추적, 다시 해 보기
  evaluator.mjs    롤아웃 평가 (워커 스레드)
  rollout.mjs      롤아웃 한 번
  determinize.mjs  가상의 판: 상대 숨은 정보 다시 뽑기
  policy.mjs       규칙 기반 AI (상대 · 롤아웃 · 선출 추천)
  coach.mjs        등급, 이유 문장, 힌트, 리뷰 요약
  story.mjs        퍼즐 단계 (데이터는 scripts/build-puzzles.mjs가 만든다)
  data/            세트 확률표, 한국어 이름 · 설명
src/               화면 (React + TypeScript)
  Battle.tsx  Field.tsx  playback.ts   배틀 화면과 턴 재생
  Lobby.tsx  Story.tsx  Preview.tsx    첫 화면, 퍼즐, 선출
  ReviewScreen.tsx  InfoSheet.tsx  TypeCalc.tsx  sound.ts
scripts/           데이터 만드는 스크립트
```

## 아직 없는 것

- 레슨, 기록 화면, 「놓친 기회」 등급
- 등급이 같은 턴에서 얼마나 흔들리는지 측정, 뉴비 대상 플레이 테스트
- 데미지 계산기로 「확정 n타」 수치 붙이기, 이유 태그 더 늘리기
- 온라인에서 바로 열기 (지금은 로컬 실행만)
- 9세대 신규 기술 · 특성 일부는 한국어 설명이 없어 쇼다운 영어 설명이 나와요
